## Question 4.9

This is Python code. Explain how this Python code implements dependency injection for a report class. In other words, what is injected?

**Before (coupled)**:

```python
class AccountingReport:
    def print_accounting_report(self):  # Directly accessing external data - BAD!
        for e in employees:  # coupling!
            print(f"{e.get_full_name()}, ${e.salary}")
```

**After (dependency injection)**:

```python
class AccountingReport:
    def __init__(self, emp_list):
        self._emp_list = emp_list  # Injected dependency

    def print_accounting_report(self):
        for e in self._emp_list:
            print(f"{e.get_full_name()}, ${e.salary}")
```
